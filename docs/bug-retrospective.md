| # | 现象 | 修复 |

| S1 | 证书测试“转义”首次失败：恶意交易标签被按字符数截断成一半，完整转义串不在输出里 | `clip()` 改为按显示宽度截断（汉字计 1，ASCII 计 0.55） |
