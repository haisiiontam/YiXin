# ADR 房间取消与主动结束

日期：2026-11-07。

用户反馈指出，创建房间后无法取消，中途也没有明确退出方式。原设计包含超时退款与争议救济，但缺少日常生命周期操作。

## 决策

1. 未匹配房间由认证房主发送 cancel-room。中继只在白方与 channelId 均为空时保存 cancelled 标记并广播，后续认证拒绝已取消房间。客户端不得将已匹配、已开通或已有双签棋谱的中继消息解释为无条件取消。
2. 未接受的链上邀请新增 cancelInvitation，仅黑方可立即取消并返还一份 stake。既有 cancelUnjoined 到期入口保留。加入与取消竞争由链上状态和交易顺序仲裁。
3. Active/Dispute 新增 resign，仅参与者可以主动让出本局，reason=4，复用合约终态与积分分配逻辑。界面二次确认，允许选择继续对局。
4. 返回大厅仅允许已结算、已取消或空闲状态，清除恢复房间指针与 URL 邀请参数，保留历史证据。
5. 活动房间不能直接加入别局或启动自动演示，客户端与界面同时约束。

## 不变量与兼容性

取消与认输不得重复支付，非参与者不得处分奖池，取消后不得加入；available points + totalLocked = totalIssued。正常对局仍为三笔交易。合约 ABI/字节码变化须使用新运行目录，保留旧部署，不静默覆盖数据库。

## 验证

新增三个实链合约用例与四个浏览器场景。首轮重复操作断言只等待提交，在缓存估算下未捕获已上链回滚；修正为等待回执，不降低权限或守恒断言。初始和最终结果分别留存于 artifacts/test-results/lifecycle-20261107 及 final 子目录。浏览器正常对局与拒签等八组回归另留 browser-regression。

本轮不实现协商和棋、Watchtower 或密钥恢复，不把断开连接视为完成链上退出。
