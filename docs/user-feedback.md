## 可直接执行的试用任务

给试用者展示已完成版本，说明仅本地教学积分，取得同意后记录匿名结果；不要求对方提供钱包私钥、真实姓名或联系方式。

| 任务 | 成功标准 | 记录方式 |
| --- | --- | --- |
| T1 首次启动与规则理解 | 能打开页面并说出黑先、五连、演示积分含义 | 实际耗时/阻塞位置/匿名原话 |
| T2 双人开局与落子 | 两个独立浏览器钱包开通并确认至少两手 | 操作录像或经同意的截图 |
| T3 终局结算 | 完成真实胜局，找到积分和3笔事务证据 | txhash/页面截图 |
| T4 理解通道负载 | 能区分链下签名、链上交易、m+2假设基线 | 解释原话，记录混淆点 |
| T5 异常退出 | 关闭自动确认、挑战并强制最后一手/超时 | 实际是否在提示下完成 |
| T6 证据核验 | 导出JSON并在另一观察钱包导入 | 验证结果与错误理解 |
